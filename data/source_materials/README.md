## 加权词频怎么算的（论文第二章 2.2、第五章 5.3.1，脚注 6）

1. 用结巴分词切分 `textbooks/` 的全部课文，先把四级词加入分词词典，保证切得出来；统计每个四级词在教材里的出现次数。
2. 教材词频与 BCC 词频分别做最小–最大规范化。
3. 总分 = 0.7 × 教材词频 + 0.3 × BCC 词频，降序排名。
4. 第 1–200 名为高频，201–400 名为中频，401–600 名为低频。

## 论文中其他资源的现状

- **中文搭配助手网站**：论文里的 `cca.xingtanlu.cn` 域名已被他人占用，变成了不相关的网站，**不要再访问**。工具现在的地址是 [cca.irishu.cn](http://cca.irishu.cn/)；我们直接用上面的原始数据，不再逐词在网站上查询。
- **HSK 动态作文语料库**（[hsk.blcu.edu.cn](https://hsk.blcu.edu.cn/)，5.3.1 易混淆词）：只能在网站上逐词人工检索，没有可下载的数据。
- **Pleco 词典**（5.3.3 义项、5.3.5 字词释义）：Pleco 内置的免费词典即开源的 CC-CEDICT（论文脚注 15），可从 [MDBG](https://www.mdbg.net/chinese/dictionary?page=cc-cedict) 下载。
- **语料库在线拼音标注**（5.3.5 句子拼音）：`corpus.zhonghuayuwen.org` 已无法访问，改用分词加拼音标注后人工核对。
- **百度翻译发音**（5.3.5）：系统用浏览器语音合成朗读，不需要音频文件。
