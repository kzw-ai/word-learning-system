# React Native App 方案（iOS / Android）

> 状态：作者已同意（2026-11 修订版）。本阶段已开始实施 M0–M2。
> 依据：`AGENTS.md` + 通读网页版与后端代码后的结论 + 作者审阅意见。

---

## 0. 结论速览

- **技术栈**：Expo SDK **58**（npm latest `58.0.x`，2026-09-29 发布；App Store 的 Expo Go 只支持最新 SDK，故必须用 58），路由用 **expo-router**，开发期用 **Expo Go**，出带真实 appId 的包时用本机 `npx expo run:ios` / `run:android`。
- **代码复用**：**复制**纯逻辑进 `mobile/`，环境相关（存储 / 请求 / 时间追踪）**重写适配**；不搞跨目录共享，避免影响网站构建。
- **身份存储**：`session_token` 存 **expo-secure-store**；`guest id` 存 **AsyncStorage**（卸载即清，正好满足「卸载重装之外不能丢」）。
- **汉字书写**：笔顺动画用 **react-native-svg 的 Mask 复刻 hanzi-writer**（中线动画当遮罩、逐笔显露字形轮廓），手写判分复用 `src/lib/handwriting.ts` 纯算法；笔画数据**打包常用字子集**，没打包的字**从网站下载并缓存**，下载失败回退打字作答。
- **音频**：`expo-audio` 播放 mp3，无音频文件的条目用 `expo-speech` 兜底；音频会话设「静音键也出声 + `duckOthers`（播放时压低其他音乐，播完恢复）」。
- **样式**：**StyleSheet + 主题 token**，不用 NativeWind；安全区用 `react-native-safe-area-context`。

## 1. 现状梳理（方案依据）

### 1.1 学习流程（网页版页面 → App 页面）

```
首页(选等级 三级/四级) index
  → 词汇知识量表 word-learning-entrance（VKS 自评 A–E，决定从哪一步进入）
  → 字 character-learning → 词 word-learning → 搭配 collocation-learning
  → 例句 sentence-learning → 练习 exercise
另有：易混淆词辨析 confusable-words、今日复习 today-review、学习看板 learning-dashboard、
     登录 login、注册 register、隐私政策 privacy
不做的开发页：phase-demo、system-status、time-tracking-demo、learning-stats
```

关键导航规则（已从 `useLearningNavigation.ts`、`LearningSessionContext.tsx`、`today-review.tsx` 读出）：
- 模块顺序 `entrance → character → word → collocation → sentence → exercise → dashboard`。
- 单字词（`characters.length === 1`，如「得」）跳过字页，从词页开始。
- 练习做完：若该词有到期易混淆词对，先进 `confusable-words`；复习模式回今日复习，否则去学习看板。
- 今日复习从列表点某词 → 按后端给的 `recommended_module` 进入对应学习页，学完回列表继续下一个。

身份规则（`user_data_isolation.py` 第 36–58 行确认）：
- 后端只认请求头 `X-Session-Token`（登录）或 `X-Guest-Id`（访客），URL/query/body 的 `user_id` 不算身份（除非 `ALLOW_USER_ID_PARAM=1`，**绝不打开**）。
- 注册时后端 `get_guest_id()` 读 `X-Guest-Id` 头，把访客记录并入新账号——所以**注册请求必须带上 `X-Guest-Id`**。

## 2. 方案正文（回答 AGENTS.md 的 10 个问题）

### 2.1 技术选型

- **Expo SDK 58**（npm latest `58.0.x`，2026-09-29 发布）。写死主版本 58；子包用 `npx expo install` 生成**精确兼容版本**并固定，一律不写 `^`（遵守规则 6）。配套 React Native 版本以脚手架生成的 `package.json` 为准，不手改。
- **路由**：`expo-router`（文件路由，等价于网页的 pages 路由，支持从看板带参数进入口页 `?wordId=`、辨析页 `?pair=` 等 query）。
- **开发方式**：先用 **Expo Go** 开发调试——本项目用到的 `expo-audio`、`expo-speech`、`expo-secure-store`、`react-native-svg`、`react-native-gesture-handler`、`react-native-reanimated`、`react-native-safe-area-context`、`react-native-screens`、`expo-router` 都在 Expo Go 内置原生模块里，能跑完整个最短流程，也能和 Capacitor 版并排装在模拟器上对比。
- **出真实 appId 的包**：用本机 **`npx expo run:ios` / `npx expo run:android`** 构建（会走 prebuild 生成本地 ios/android 工程并编译），**不用 EAS 云构建**。最终替换上架时把 appId/名字换成正式值再出正式包。
- **安卓 Gradle 依赖**：本机 `dl.google.com` 连不上，**Gradle 镜像由作者统一配置**。构建时若因 Gradle 依赖下载失败，**先报告、不自行改全局配置**。

### 2.2 代码复用策略

见 1.3 表。落地方式：
- `mobile/src/lib/` 复制 `handwriting.ts`、`fillHint.ts`、`reviewTime.ts`、`types.ts`、`activeTime.ts`（纯逻辑）。
- `mobile/src/lib/` 重写 `apiClient.ts`、`authHeaders.ts`、`authClient.ts`、`guestIdentity.ts`、`timeTracker.ts`。
- 判分算法是「同一份逻辑」的核心：`handwriting.ts` 里除 `loadCharacterData` 外一行不改地搬，改动时同步回网页版（或加一条 TODO 提醒）。

### 2.3 登录凭证和 guest id 存哪里

- `session_token`（敏感）：**expo-secure-store**（iOS Keychain / Android Keystore）。启动时用 `GET /api/auth/validate` 校验，失效即清掉并退回访客（照搬 `LearningContext.tsx` 的校验逻辑）。
- `guest_id`：**AsyncStorage**。理由：iOS 的 Keychain 在卸载重装后仍保留，会违背「卸载重装之外不能丢」的语义（重装应视为新访客）；AsyncStorage 在卸载时清空，正符合要求。guest id 生成算法照搬 `guestIdentity.ts`（`guest_` + 20 字节随机 → 62 字符表映射）。
- 其余非敏感本地状态（学习位置本地镜像、`fill-input-mode`、引导已看、`review-first-skipped` 等）也放 AsyncStorage。
- 请求头逻辑：`getAuthHeaders()` → 有 token 发 `X-Session-Token`，否则发 `X-Guest-Id`；注册/登录时也始终带上 `X-Guest-Id`，让后端并入访客记录。

### 2.4 汉字书写（最难的一块）

#### 2.4.1 笔顺动画：用 Mask 复刻 hanzi-writer

- **做法（复刻 hanzi-writer 观感）**：hanzi-writer-data 每个字给 `strokes`（SVG 轮廓路径串，实心字形）和 `medians`（笔画中线点列，1024 见方、y 轴朝上、基线 900）。用 `react-native-svg` 的 `<Mask>`：
  1. 底层画**完整字形轮廓**（用 `strokes` 的 `<Path>` 填充，颜色淡如浅灰）；
  2. 遮罩层按笔顺逐笔画出**中线**（`medians` 连线成粗 path），用 `Animated` 驱动中线的 `strokeDasharray/offset` 从 0 到全长推进；
  3. 因为 Mask 以「已画出的中线」为可见区，字形轮廓就**逐笔显露**，观感与网站 hanzi-writer 一致。
- 判分函数 `targetStrokes()` 已做 y 轴翻转，动画与判分共享同一份 `medians`/`strokes` 数据，不自造第二套。
- **保底**：若 Mask 方案在 RN 里做不出理想效果，退回「中线画粗线条逐笔揭示」的简版并**主动告知作者**（不是静默降级）。
- 可重播：清空遮罩中线进度重放。

#### 2.4.2 手写输入和判分

- 手写格：`react-native-svg` + 手势采集（`react-native-gesture-handler` 的 `Pan`，或 `PanResponder`），按网页版 `HandwritingPad` 同样的 240×240 逻辑坐标记录 `Point[]` 笔画数组，支持 Undo / Clear / 田字格底纹 / 对错描边。采集的是坐标，不是 canvas 像素，`gradeHandwriting` 直接吃这个数据结构。
- 判分：`gradeHandwriting` / `resample` / `normalise` / `strokeCost` 纯 TS，原样复用；`alsoCorrect`（如「师傅/师父」的「父」）逐字判分逻辑照搬 `exercise.tsx` 的 `handleSubmit`。取不到答案字笔画数据时回退「打字作答」（同网页行为）。
- 打字作答备选：`TextInput`（系统输入法含手写/拼音），保留。

#### 2.4.3 笔画数据：打包子集 + 网站下载缓存

- **打包常用字子集**：构建时用一个小脚本（仿 `scripts/copy_hanzi_data.js`）扫描 `data/learning_materials/hsk3`、`hsk4`（含 `hanzi`、`characters[].character`）提取所有唯一汉字，再从 `hanzi-writer-data` 复制**只含这些字**的 JSON 到 `mobile/src/assets/hanzi-data/`，生成一张 `char → require(...)` 的静态索引文件打包进 App。子集远小于全量（9000 字），体积可控。
- **按需下载兜底**：遇到没打包的字，从 **`https://learnchinese.kzwbelieve.top/hanzi-data/<字>.json`** 下载（与网站同域名，Flask 的 CORS 已放行该来源），**下载成功即缓存**到本地（AsyncStorage 或文件系统），后续离线可用；**下载失败再回退打字作答**（同网页 `loadCharacterData` 返回 null 的行为）。
- 运行时 `loadCharacterData(char)` 顺序：打包索引命中 → 本地缓存 → 网站下载并写缓存 → 抛错（调用方回退打字）。
- 实现时再核对 `step7_build.py` 的 ALSO_CORRECT 字表（如「父」）并纳入打包子集。

### 2.5 音频

- 主路径：`expo-audio` 播放 `buildApiUrl(audioUrl)`（mp3 相对路径拼后端地址）。
- 兜底：`audio` 为空串（网页版用浏览器 TTS）的条目，用 **`expo-speech`**（iOS AVSpeechSynthesizer / Android TTS）读 `text`，语速约 0.9（对齐网页版）。
- 音频会话（`expo-audio` 的 `setAudioModeAsync`）：
  - iOS `playsInSilentModeIOS: true`——学习音频在**静音键开启时也出声**（语言学习 App 的核心内容）。
  - `interruptionModeIOS: 'duckOthers'`——播放时**压低其他 App 的音乐**，播完自动恢复，不停掉音乐。
  - Android 默认即可，注意 `shouldPlayInBackground: false`。

### 2.6 界面

- **配色/字号**：沿用网页版 token——主色 indigo→violet 渐变、`glass-panel`（白 90% + 细边框 + 浅阴影）、`glass-card`、底色 `slate-50→indigo-50/40→slate-100`、正文 ≥14（`text-sm`）、按钮高 ≥36（`h-9`）、主按钮 48（`h-12`）。
- **样式方案**：**StyleSheet + 一个 `theme.ts` 常量文件**（颜色、字号、圆角、间距、按钮高度）。不用 NativeWind 的理由：网页版大量样式靠 CSS 特性（`env(safe-area-inset-*)`、`backdrop-blur`、`mix-blend-multiply` 光斑、`max-height:700px` 断点）这些在 NativeWind/RN 里没有 1:1 映射，抄类名也抄不来，反而引入构建依赖和心智负担；RN 项目常规做法就是 StyleSheet + 主题 token，可控、可测。
- **安全区**：`react-native-safe-area-context` 的 `useSafeAreaInsets`（刘海/底部横条），替代网页的 `env(safe-area-inset-*)`。
- **响应式**：用 `useWindowDimensions()` 按高度分档，替代 Tailwind 的 `short/roomy/tall`（<700 紧凑、≥760 手写格放大、≥860 显示自评页统计栏）；宽度仍按 430px 限宽设计，窄屏自适应。
- **键盘遮挡**：`KeyboardAvoidingView`（或 `react-native-keyboard-controller`）确保填字输入框不被软键盘遮住——对齐网页版 Capacitor 里的 `Keyboard` 监听逻辑。
- **背景光斑装饰**：可用绝对定位的半透明 `View` + 大圆角近似，或直接省略（不影响功能，可后续补）。

### 2.7 学习时长和事件上报

- **v1 策略（按作者意见）：「App 在前台就算在学」**——前台即视为活动，`idle_gap` 只在切后台这一处产生（移动 App「人走开」= 锁屏/切后台，比网页「开着页面走开」更清晰）。
- 保留后端事件协议不变（`session/start|end|initial-level`、`exercise/record`、`events/batch`，字段照旧），只改「活动感知」层：
  - **前后台**：`AppState.addEventListener('change', ...)` 替代 `document.visibilitychange`。切后台时先 `accrue` 到上限、标记 inactive、flush 事件；回前台重置 `lastActiveTime`。
  - **结束时机**：页面卸载（`endSession(true)`）与 App 切后台（flush）两个点，替代网页的 `beforeunload`。30s 批量定时器保留，但 iOS 后台定时器会被挂起，所以切后台时强制 flush 一次。
  - `sendRecommendationFeedback` 去掉 `keepalive`（RN 无此概念），fire-and-forget。
- 复用 `splitGap` / `DEFAULT_IDLE_CAP_SECONDS` / 事件类型名，保证看板统计口径一致。

### 2.8 appId 和名字

- 开发期 `app.json`：`ios.bundleIdentifier` / `android.package` = `top.kzwbelieve.learnchinese.rn`，`name` = `Word Learning RN`（与 Capacitor 版 `top.kzwbelieve.learnchinese` / `Word Learning` 并存）。
- 替换上架时：改成 `top.kzwbelieve.learnchinese` / `Word Learning`，再出正式包。
- 出包方式：**本机 `npx expo run:ios` / `run:android`**（不用 EAS）。Expo Go 里 appId 是 Expo Go 自己的，真 appId 要 run/prebuild 出的包才生效；开发期靠 Expo Go 不影响，只要 `app.json` 里先把值预留好。

### 2.9 分步计划（先最短闭环，再补全）

每一步都「小步提交、跑测试、可验证」。

| 阶段 | 内容 | 验证方式 | 预估工作量 |
|---|---|---|---|
| **M0 脚手架** | `create-expo-app` 初始化 `mobile/`（SDK 58、expo-router、TS）；根 `tsconfig.json` 的 `exclude` 加 `"mobile"`；确认 `npm run build` 仍通过 | 网站 `npm run build` 通过 | 0.5 天 |
| **M1 身份 + 请求层** | 复制纯逻辑文件；重写 `apiClient/authHeaders/authClient/guestIdentity`；SecureStore + AsyncStorage 落地；启动时校验 token | 单元测试（guest id 生成/校验、URL 拼接、请求头）+ 真机看请求头 | 1–1.5 天 |
| **M2 最短闭环** | 首页(选等级) → 入口(VKS) → 词 → 搭配 → 例句 → 练习（先只做选择题，手写格暂用打字），含学习会话追踪 | Expo Go 走通「选等级→学一个新词各步→练习」；后端看板有会话记录 | 3–4 天 |
