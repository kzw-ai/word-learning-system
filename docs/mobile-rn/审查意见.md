### 16. M8 音频的问题（针对 3f7d42f，Claude 代码审查 + iOS 实测）

已处理：DeepSeek 4cc0382 逐条改完。Claude iOS 复验（WL iPhone SE，重新 prebuild --clean）：Info.plist 里已没有 `UIBackgroundModes` 和 `NSMicrophoneUsageDescription`，安卓清单只剩 `MODIFY_AUDIO_SETTINGS`；词页发音 0.3 秒变「播放中」、2.3 秒放完复位；播放中再点能停；把一个例句的音频指向不存在的文件（404）后退回系统朗读（日志里加载了 TTS）。

原意见：


iOS 已重新 prebuild、pod install、构建（WL iPhone SE）。实测：练习题答完后「而」旁出现 🔊，点了之后后端收到 `GET /api/audio/*.mp3`，系统日志里播放器进入 Playing、音频队列在工作，**声音能放出来**。问题如下：

1. **【严重】放文件时按钮一直转圈**：`handlePlay` 走文件分支后只 `setIsLoading(true)`，之后没有任何地方把 `isLoading` 改回 false、把 `isPlaying` 改成 true（只有朗读的 `onStart` 会改），`onPlay` 也不会被调用。iOS 实测点击后 0.5、1.5、3、5、8 秒都是转圈（这段音频约 1 秒）。后果：播放中点了停不下来，放完也回不到 🔊。修法：用 `status.playing` 或 `status.isLoaded` 的变化驱动状态（开始播放时 `isLoading=false`、`isPlaying=true` 并调用 `onPlay`），`didJustFinish` 时复位。
2. **【严重】学习页和辨析页没有发音按钮**：网页版 `components/learning/WordBlocks.tsx` 里，整词（标题旁）、每个字、每条搭配、每个例句都有 `AudioPlayer`，`pages/confusable-words.tsx` 里两个词各有一个；RN 版只接在了练习选项上。数据已经有了（`types.ts` 里 `audio` 字段），照网页版位置接上，搭配一样去掉括号拼音再朗读。
3. **【上架会卡】expo-audio 插件默认加了用不到的权限**：现在 Info.plist 里多了 `UIBackgroundModes: audio` 和 `NSMicrophoneUsageDescription`，安卓会加 `RECORD_AUDIO`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK` 和一个前台播放服务。我们不录音、也不在后台放音，App Store 审核会因为「声明了后台音频但没有后台播放功能」退回，Google Play 也要求为前台服务和录音权限填写用途说明。改成：
   ```json
   ["expo-audio", { "microphonePermission": false, "recordAudioAndroid": false, "enableBackgroundPlayback": false }]
   ```
   改完 `npx expo prebuild --clean` 检查 Info.plist 和 AndroidManifest 里这几项都没了。
4. **文件加载慢时会两个声音一起放**：3 秒超时只看 `!isLoaded && !playing`，网络慢时回退到朗读，但 `player.play()` 已经发出，文件随后加载完照样会放。回退时先 `player.pause()`；判断失败也可以直接看 `status.error`（expo-audio 的状态里有这个字段，加载失败时有值），不必只靠超时。
5. **朗读的回调没核对编号**：`onDone`、`onStopped`、`onError` 没有检查 `attempt === attemptRef.current`。`speak()` 开头的 `Speech.stop()` 会触发上一次朗读的 `onStopped`，它可能晚于新一次的 `onStart` 到达，把正在朗读的按钮改回未播放。三处加上和 `onStart` 一样的判断。
6. **小问题**：
   - 发音按钮嵌在选项的 Pressable 里，无障碍树里被并进「C., 而」，VoiceOver 用户点不到它单独发音。给外层选项 Pressable 在答完后设 `accessible={false}`，或把按钮移到选项外面。
   - 转圈用的 `colors.textFaint`，放在答对的绿底上几乎看不见（截图 `.review/app-rn-ios/au-t*.png`），在深底上换成浅色。
   - `setAudioModeAsync` 每个按钮挂载都调一次，可以挪到根布局只调一次。

键盘、安全区、小屏这次没有改代码，沿用之前的实现。M7 在 iPhone SE 上走查注册和登录时，输入和提交都正常。修完第 1 到 3 处后，第 3 处需要重新原生构建，iOS 仍由 Claude 构建和复验。
